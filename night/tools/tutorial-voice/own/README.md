Put your own narration here, one file per line, named after the line:
intro, tap, weave, hold, voices, depth, tide, tape, animate, hum, mood, sleep, bye
(for example `tap.wav` or `tap.m4a`). The script lives in night/tools/TUTORIAL-SCRIPT.md.
Any line with a file here uses your voice; the rest fall back to the computer voice.
Then run: node night/tools/make-tutorial.mjs
